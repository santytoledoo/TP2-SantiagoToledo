# UTN Social — Red Social Full-Stack (TP2)

Aplicación web full-stack de red social desarrollada para la **Tecnicatura Universitaria en Programación** (Universidad Tecnológica Nacional — Facultad Regional Avellaneda). Permite a los usuarios registrarse, iniciar sesión, gestionar su perfil con foto y biografía, y compartir publicaciones con imágenes e interacciones en tiempo real.

---

## Enlaces en Producción

* **Aplicación Web (Frontend en Vercel):** [https://utn-social-tp2.vercel.app](https://utn-social-tp2.vercel.app)
* **API REST (Backend en Render):** [https://tp2-santiagotoledo.onrender.com](https://tp2-santiagotoledo.onrender.com)

---

## Tecnologías Utilizadas

* **Frontend:** Angular, TypeScript, HTML5, CSS3, RxJS (`HttpClient`, Standalone Components).
* **Backend:** NestJS, TypeScript, Mongoose, `bcrypt`, `class-validator`, `class-transformer`.
* **Base de Datos:** MongoDB Atlas (en la nube).
* **Despliegue:** Vercel (Frontend SPA con manejo de rutas mediante `vercel.json`) y Render (API REST Node.js).

---

## Funcionalidades Principales

* **Registro e Inicio de Sesión:** Alta de usuarios con validación de campos, contraseña encriptada con `bcrypt` y login mediante correo electrónico o nombre de usuario (`@username`).
* **Muro de Publicaciones (`/publicaciones`):**
  * Creación de publicaciones con título, descripción e imagen (con redimensionamiento y optimización automática).
  * Listado paginado desde el backend (`page` y `limit`).
  * Ordenamiento dinámico por **más recientes** o **más Me gusta**.
  * Sistema de *Me gusta* (toggle) y eliminación de publicaciones propias con confirmación.
  * Sincronización automática de la foto de perfil y datos del autor en todas sus publicaciones.
* **Perfil de Usuario (`/mi-perfil`):**
  * Visualización limpia de datos del usuario, biografía, métricas de publicaciones y *Me gusta* recibidos.
  * Cambio rápido de foto de perfil desde el avatar o edición completa de nombre, apellido, usuario, correo, fecha de nacimiento y biografía (hasta 160 caracteres).
  * Listado paginado de las publicaciones propias del usuario.

## Ejecución en Entorno Local

### 1. Clonar el repositorio
```bash
git clone [https://github.com/santytoledoo/TP2-SantiagoToledo.git](https://github.com/santytoledoo/TP2-SantiagoToledo.git)
cd TP2-SantiagoToledo
```

### 2. Levantar el Backend (`red-social-back`)
```bash
cd red-social-back
npm install
npm run start:dev
```
El servidor queda escuchando en `http://localhost:3000`.

### 3. Levantar el Frontend (`red-social-front`)
En otra terminal:
```bash
cd red-social-front
npm install
npm start
```
La aplicación queda disponible en `http://localhost:4200`.
